# Word Counter

A fast, private, free word counter that runs entirely in your browser. Paste or type text to instantly see word, character, sentence, and paragraph counts along with an estimated reading time.

Built by **Ethereal Studios**.

## Features

- **Live statistics**: words, characters, characters without spaces, sentences, paragraphs, and reading time (based on 200 words per minute)
- **Private**: all processing happens locally; no text ever leaves your browser
- **Copy & Clear**: one-click copy to clipboard and clear buttons
- **Keyboard shortcut**: `Ctrl/Cmd + Shift + K` clears the text
- **Light / Dark theme**: follows your system preference and remembers your choice
- **Responsive**: works on desktop and mobile
- **No dependencies**: plain HTML, CSS, and JavaScript

## Deploying to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. The site will be published at `https://builtbyethereal.github.io/WordCounter/`.
